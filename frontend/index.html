HELP CENTRE

Questions, answered.

Quick answers to help you keep moving.

Do I need to know Git before starting?

No. Start with the first module. The course assumes you are new to version control.

Does the practice terminal change my real files?

No. It is a simulator that recognises a small set of educational commands. Use your own terminal for real projects.

Why create an account?

An account lets the backend save completed lessons and quiz attempts so your progress is available again after you log in.

Can I use GitHub Pages to host the entire platform?

GitHub Pages can host the static frontend, but not the FastAPI backend or database. Deploy the backend separately and configure the frontend API URL.

Are the videos hosted by Git Academy?

No. Video cards link to YouTube search results so you can choose a current tutorial. Check the title, publisher, and content before relying on a video.

Is the leaderboard a ranking of coding ability?

No. It only reflects lesson completion and quiz scores recorded by the platform. It is a learning motivation feature, not a measure of professional ability.
